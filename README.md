# Enterprise RAG Document Intelligence System

## Overview
An enterprise-grade RAG system that allows employees
to retrieve information from internal company documents
and receive accurate, source-grounded answers.

## Features
- PDF and DOCX document ingestion
- Text extraction and preprocessing
- Document chunking
- Embedding generation
- Vector database storage
- Hybrid search
- Reranking
- LLM-based answer generation
- Source citations
- RAG evaluation

## Tech Stack
- Python
- LangChain
- LangGraph
- FastAPI
- PostgreSQL
- Qdrant
- OpenAI / Local LLMs
